\pagebreak
\unnumberedSection{RUN - Run the simulation}

%--------------------------------------------------------------------------------
\begin{iPageDescEntry}{Syntax}
\texttt{RUN [  ]} \
\end{iPageDescEntry}

%--------------------------------------------------------------------------------
\begin{iPageDescEntry}{Description}

The \texttt{RUN} command starts or resumes continuous execution of the
simulation. Once invoked, control is transferred to the TWIN-64 system and
all configured and enabled processor and I/O modules are allowed to execute.

Unlike the \texttt{STEP} command, \texttt{RUN} does not specify a finite
number of execution units. Execution continues until a system-wide stop
condition occurs, such as a breakpoint, a simulator trap, or another
condition that returns control to the simulator command interface.

A processor module encountering a breakpoint or a simulator trap causes the
entire simulation to enter the HALT state. All modules are then stopped and
control returns to the simulator command interface.

Because the modules execute concurrently in separate threads, they do not
necessarily execute the same number of instructions or execution units before
a system-wide halt occurs. The module may therefore have executed fewer or 
more units than the module that encounters the stopping condition.

\end{iPageDescEntry}

%--------------------------------------------------------------------------------
\begin{iPageDescOpEntry}{Example}
\begin{lstlisting}[style=iPageOpStyle]

(80)->run             # start continuous simulation execution

\end{lstlisting}
\end{iPageDescOpEntry}

%--------------------------------------------------------------------------------
\begin{iPageDescEntry}{Notes}

The \texttt{RUN} command honors the enabled code and data breakpoints.
When a breakpoint is encountered, the entire simulation is halted and
control returns to the simulator command interface.

Trace settings, when enabled, may likewise cause execution to stop according
to their configured behavior.

\end{iPageDescEntry}
