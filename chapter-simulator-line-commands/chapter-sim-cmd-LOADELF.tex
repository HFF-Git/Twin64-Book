\pagebreak
\unnumberedSection{LOADELF - load ELF file}

%--------------------------------------------------------------------------------
\begin{iPageDescEntry}{Syntax}
\texttt{loadelf "<filePath>" } \\
\end{iPageDescEntry}

%--------------------------------------------------------------------------------
\begin{iPageDescEntry}{Description}

The \texttt{LOADELF} command opens an ELF format file and places the ELF segments at the in the ELF file specified address in memory. 

This command is currently under construction and will be finalized when the actual ELF file segments and sections are defined for Twin-64. Currently, it just loads the ELF segments at the specified physical address.

\end{iPageDescEntry}
